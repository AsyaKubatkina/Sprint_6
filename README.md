# Sprint_6 - UI автотесты для Яндекс.Самокат

Проект автотестов на **Python + Selenium + Pytest** для учебного сервиса **«Яндекс.Самокат»**.  
Реализован подход **Page Object Model (POM)** и подключён **Allure-отчёт**.

## Что покрыто тестами

### 1. FAQ («Вопросы о важном»)
- Проверка: при клике на каждый вопрос открывается соответствующий ответ.
- Реализовано через параметризацию (отдельная проверка для каждого вопроса).

### 2. Заказ самоката (позитивный сценарий)
- Полный флоу оформления заказа.
- 2 набора тестовых данных.
- 2 точки входа: **верхняя** и **нижняя** кнопки «Заказать» (через параметризацию).

### 3. Логотипы
- Клик по логотипу **Самокат** возвращает на главную страницу (проверка заголовка/страницы).
- Клик по логотипу **Яндекс** открывает страницу в новой вкладке (проверка видимости поля поиска).

---

## Структура проекта

- `pages/` — Page Object классы
- `locators/` — локаторы страниц
- `tests/` — тесты
- `data.py` — тестовые данные (в том числе для параметризации)
- `conftest.py` — фикстуры (`driver`, `prepared_driver` и т.д.)
- `requirements.txt` — зависимости
- `allure-report/` — **сгенерированный Allure-отчёт (закоммичен по требованию задания)**

## Установка и запуск (macOS / Linux)

### 1. Создать и активировать виртуальное окружение
```bash
python3 -m venv .venv
source .venv/bin/activate

### 2. Создать и активировать виртуальное 
pip install -r requirements.txt

### 3. Запуск всех тестов
pytest -v

### 4. Allure-отчет: Сгенерировать результаты
pytest -v --alluredir=allure-results

### 5. Allure-отчет: Сгенерировать HTML отчет
allure generate allure-results -o allure-report --clean

### 6. Allure-отчет: Открыть отчет локально
allure open allure-report
